# Simple Student Allowance Budget Tracker
*Project by: Clarence Rudio*

Good day!

This simple web‑based allowance tracker helps students log their allowance and daily expenses. It automatically calculates total spending and remaining money using HTML, CSS, and JavaScript in VS Code.

## Project Purpose
This application lets students set their weekly allowance, record daily expenses such as fare and snacks, and view their remaining budget. It helps practice good money management.

## Tools Used
- VS Code – for writing and editing code
- HTML – for app layout
- CSS – for simple design
- JavaScript – for allowance and expense calculations
- Live Server – for testing the web app
- GitHub – for hosting the finished project

## How it works
1. Enter your total allowance and click Set Allowance.
2. Add daily expenses like fare or snacks.
3. The app automatically computes total spent money and remaining balance.
4. It shows a list of all recorded expenses.

## How to Install and Run
Open the live link below, or
